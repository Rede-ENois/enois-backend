# Vocabulário de palpites

`palpites-pt-br.txt` deriva de [Lista de todas as palavras do português brasileiro](https://www.ime.usp.br/~pf/dicios/), de Paulo Feofiloff, baseada no trabalho de Ricardo Ueda Karpischek para o dicionário br.ispell. A página informa licença [Creative Commons Attribution (CC BY)](https://creativecommons.org/licenses/by/4.0/).

Fonte: `br-sem-acentos.txt`, obtida em 2026-10-18. Transformações: selecionar linhas de exatamente cinco letras ASCII, converter para maiúsculas, ordenar e remover duplicatas. A fonte informa que a lista pode conter erros e omissões; não é um dicionário normativo. O arquivo contém 5.427 entradas. As respostas são uma lista pequena, separada e curada no projeto.

SHA-256 do conteúdo de texto fonte recebido (codificado novamente como UTF-8): `2EB81AFE3EA215DFEA59890021E8CEBB9F3B71A80FE6A56DFB29F84E2870B0DB`.
